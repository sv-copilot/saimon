# AI-DETECTION-1 Design Document

- **Slice**: AI-DETECTION-1
- **Branch**: `slice/AI-DETECTION-1`
- **Status**: 📋 designed
- **Parent**: ai-dev

## Problem Statement

The evaluate MCP currently has 5 quality criteria (clarity, completeness,
coherence, conciseness, tone_match).  None detect whether content was
generated by an LLM.  As LLM-generated content proliferates, users need a
deterministic way to assess how "AI-like" a piece of text reads.

This slice adds a sixth criterion — `ai_detection` — that uses pure
deterministic pattern matching (no LLM calls) to produce a 0.0–1.0 score.
0.0 means "definitely AI-generated" (many fingerprints matched), 1.0 means
"passes as human-written" (no fingerprints found).

## Design Decisions

### Why deterministic, not LLM-based

1. **No recursion**: Asking an LLM "does this sound like AI?" is circular
   and unreliable — LLMs are known to hallucinate and exhibit self-bias.
2. **Heuristic fallback**: The evaluate MCP already has a `_score_criterion`
   function for use when the LLM is unavailable.  This criterion is
   purely heuristic and never calls the LLM.
3. **Reproducibility**: Deterministic checks give the same score every time
   for the same input, which is essential for quality gates.
4. **Speed**: Pattern matching is O(n) on text length with no API latency.

### Score interpretation

- **0.0**: Definitive AI fingerprints — multiple template phrases, bullet
  addiction, formulaic transitions.
- **0.5**: Mixed signals — some AI patterns but also personal stance or
  natural flow.
- **1.0**: No AI fingerprints detected — reads as human-written.

## The 6 Checks

Each check returns 0.0–1.0 and a justification string.  The overall
`ai_detection` score is the unweighted average (equal 1/6 weight per
check).

### Check 1: Template Phrases

Count occurrences of known LLM fingerprints:

```
delve into, it's worth noting, moreover, furthermore, thus,
in conclusion, as an AI, it is important to note,
crucial to understand, plays a pivotal role
```

Score formula: `max(0.0, 1.0 - (match_count / max(1, sentence_count) * 2))`

Each match counts as a penalty.  2+ matches in a short text triggers a
strong penalty.  The multiplier of 2 means if more than half of sentences
have a template phrase, the score floors at 0.0.

### Check 2: Over-Hedging

Two sub-checks:

a) Count "on one hand"/"on the other hand" pairs.  Each pair counts as 1
   hedge marker.
b) Count "however" and "nevertheless" per 100 words.

Score formula: `max(0.0, 1.0 - (hedge_markers / max(1, words/100)))`

A density over 1 hedge marker per 100 words starts reducing the score.

### Check 3: Adjective Inflation

Count occurrences of overused LLM adjectives:

```
robust, comprehensive, crucial, paramount, multifaceted,
holistic, dynamic, vibrant
```

Score formula: `max(0.0, 1.0 - (adj_count / max(1, words/100)))`

### Check 4: Bullet-Point Addiction

Calculate the ratio of list items (lines starting with `-`, `*`, or
numbered `1.`) to narrative paragraphs (blocks of text separated by
blank lines).

Score formula:
- If `bullet_ratio > 0.7`: `0.0` (heavily flagged)
- If `bullet_ratio > 0.4`: `0.5`
- Otherwise: `1.0`

### Check 5: No Personal Stance

Check for first-person singular markers:
```
I think, I found, in my experience, I believe, I noticed,
I discovered, I feel, I've found, I have found, in my opinion
```

Score formula: `min(1.0, personal_count / 2.0)`

At least 2 personal markers → score of 1.0 (human-like).  0 markers → 0.0.

### Check 6: Formulaic Transitions

Detect consecutive paragraphs starting with ordered transition words:

```
First, Secondly, Third, Finally, In conclusion, Lastly,
To begin, Next, Additionally
```

Score formula: `max(0.0, 1.0 - (transition_count / max(1, paragraph_count)))`

If more than half the paragraphs use formulaic transitions, score hits 0.0.
